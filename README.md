# hypr
This configuration of hyprland window manager is intended for the forgetful. It is vim oriented to make remembering easier.
**Super + space** - Menu
**Super + Enter** - terminal
**Super + t** - tmux
**Super + f** - nautilus file manager
**Super + h/j/k/l** - change focus to next window on that direction
**Super + Ctrl + h/l** - change workspace to previous/next that has open windows
**Super + r** - resize focused window. This is to be __followed__ by **h/j/k/l** to do the
            actual resizing to that direction. __Terminate__ with **Esc** or **Enter**
**Super + m** - move the current focused window. This is to be __followed__ by
            **h/j/k/l** to move it to that direction. __Terminate__ with **Esc** or **Enter**
**Super + q** - quit that window
**Super + z** - zoom in/out (toggles between full screen and original size)
**Super + w** - Window manager toggle, between tiling and scrolling (like niri) window manager

Firefox is automatically started upon login.
Other apps are very easy to find from the rofi menu; just type a few letters and it home-in to that app. It is not worth remembering another keybind just to start them up. Define another keybind if you find yourself using it all the time and searching from rofi is painful.
